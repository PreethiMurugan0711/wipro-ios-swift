# Topic 2: Swift Fundamentals – Variables and Constants

## Overview

This topic covers Swift variables, constants, data types, type annotations, string interpolation and mutability.

## Learning Objectives

- Understand the difference between `let` and `var`.
- Learn Swift data types.
- Understand type inference and type annotation.
- Use string interpolation.
- Perform type checking using `type(of:)`.
- Understand compiler errors related to mutability and type mismatches.
